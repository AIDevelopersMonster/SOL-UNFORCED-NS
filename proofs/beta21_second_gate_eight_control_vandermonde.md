# Eight-control Vandermonde theorem for the routed second beta-(2,1) gate

**Status:** PROVED EXACT FROZEN PRINCIPAL RANK THEOREM FOR A SUFFICIENT CLEAN SECOND-GATE BLOCK. After routing the old catalyst out of the second overlap, include the total beta-two `P` trace as an explicit output coordinate. Then the promoted chain generated by the unavoidable difference child becomes an eight-state single-input triangular control system. Because the direct control has a nonzero component in the first state `C_new`, the Kalman/Volterra response basis is triangular with consecutive polynomial degrees `0,...,7`. Eight translated copies of one smooth compact source profile therefore give an exact ordinary Vandermonde determinant.

A sufficient clean second-gate block is

\[
\boxed{
\mathcal Y_2^{clean}
=(C_{new},P,E,G_4,G_5,G_6,G_7,G_8).
}
\]

The target may be taken as

\[
\boxed{
(C_{new},P,E,G_4,G_5,G_6,G_7,G_8)_{out}
=(0,0,E_*,0,0,0,0,0),
\qquad E_*\ne0.
}
\]

This is a sufficient rather than minimal formulation. It trades one extra control for a completely transparent consecutive-degree Vandermonde theorem.

## 1. Frozen eight-state chain

Let

\[
X_1=C_{new},\quad X_2=P,\quad X_3=E,
\quad X_4=G_4,\ldots,X_8=G_8.
\tag{S2V1}
\]

Freeze one short second collision collar and normalize diagonal homogeneous transport away by integrating factors. The principal triangular dynamics generated by repeated attachment of the surviving unit-beta packet `D` has the form

\[
X_1'=bq,
\tag{S2V2}
\]

\[
X_2'=c_1X_1,
\tag{S2V3}
\]

\[
X_3'=a q+c_2X_2,
\tag{S2V4}
\]

\[
X_{j+1}'=c_jX_j,
\qquad j=3,\ldots,7.
\tag{S2V5}
\]

Here `q` is the scalar direct control profile produced by a localized perturbation of the `P-D` collision, while

- `b` is the principal difference coefficient `P-D -> C_new`;
- `a` is the principal sum coefficient `P+D -> E`;
- `c_j` are the principal repeated-`D` attachment coefficients along

\[
C_{new}+D\to P,
\quad
P+D\to E,
\quad
E+D\to G_4,
\ldots,
G_7+D\to G_8.
\tag{S2V6}
\]

The direct `E` term `a q` does not destroy triangular controllability; it lies two rows below the first direct control component.

All margins are fixed `O(1)` numbers, so sufficiently high-level source-frame perturbations cannot change their nonvanishing.

## 3. Controllability matrix

Write the system as

\[
X'=AX+Bq,
\tag{S2V11}
\]

with

\[
B=be_1+ae_3.
\tag{S2V12}
\]

The matrix `A` is the weighted forward shift

\[
Ae_j=c_je_{j+1},
\qquad j=1,\ldots,7.
\tag{S2V13}
\]

Consider the controllability matrix

\[
\mathcal C
=[B,AB,A^2B,\ldots,A^7B].
\tag{S2V14}
\]

The contribution of `b e_1` to the `k`th column is

\[
A^k(be_1)
=b(c_1\cdots c_k)e_{k+1},
\tag{S2V15}
\]

with the empty product equal to one. The `a e_3` contribution lies strictly below this diagonal position. Therefore `\mathcal C` is lower triangular with diagonal

\[
b,
\quad bc_1,
\quad bc_1c_2,
\quad\ldots,
\quad bc_1c_2\cdots c_7.
\tag{S2V16}
\]

Hence

\[
\boxed{
\det\mathcal C
=b^8c_1^7c_2^6c_3^5c_4^4c_5^3c_6^2c_7
\ne0.
}
\tag{S2V17}
\]

Thus the frozen eight-state system is controllable from one scalar source channel.

## 4. One translated smooth source profile

Fix

\[
q\in C_c^\infty(\mathbb R),
\qquad
\mu_k:=\int r^kq(r)\,dr,
\quad 0\le k\le7,
\tag{S2V18}
\]

with

\[
\boxed{\mu_0\ne0.}
\tag{S2V19}
\]

For the translate

\[
q_\tau(v)=q(v-\tau),
\qquad
L=v_+-\tau,
\tag{S2V20}
\]

the exact frozen exit response is

\[
K(\tau)
=\int e^{A(L-r)}Bq(r)\,dr.
\tag{S2V21}
\]

Since `A^8=0`,

\[
K(\tau)
=\sum_{k=0}^{7}
\frac{A^kB}{k!}
\int(L-r)^kq(r)\,dr.
\tag{S2V22}
\]

Each moment polynomial has exact degree `k` in `L` with leading coefficient `\mu_0`. Therefore there is an invertible lower triangular moment matrix `M_q` such that

\[
K(\tau)
=
\mathcal C\,
\operatorname{diag}(1,1/1!,\ldots,1/7!)
M_q
(1,L,\ldots,L^7)^T,
\tag{S2V23}
\]

and

\[
\boxed{
\det M_q=\mu_0^8.
}
\tag{S2V24}
\]

## 5. Eight translated controls

Choose eight distinct centers

\[
\tau_1,\ldots,\tau_8
\]

with

\[
L_j=v_+-\tau_j.
\]

Let `J_8` be the `8 x 8` exit matrix whose `j`th column is `K(\tau_j)`. Combining (S2V17)--(S2V24),

\[
\boxed{
\det J_8
=
\frac{
 b^8c_1^7c_2^6c_3^5c_4^4c_5^3c_6^2c_7
}{1!2!3!4!5!6!7!}
\mu_0^8
\prod_{1\le i<j\le8}(L_j-L_i).
}
\tag{S2V25}
\]

In particular,

\[
\boxed{
\mu_0bc_1\cdots c_7\ne0,
\quad
\tau_i\ne\tau_j
\Longrightarrow
\det J_8\ne0.
}
\tag{S2V26}
\]

The direct `E` coefficient `a` drops out of the determinant. It changes only lower-triangular entries, not controllability.

## 6. Equal spacing

If

\[
L_j=L_0+(j-1)\Delta,
\qquad j=1,\ldots,8,
\tag{S2V27}
\]

then

\[
\prod_{i<j}(L_j-L_i)
=\Delta^{28}\prod_{k=1}^{7}k!.
\tag{S2V28}
\]

Hence all factorials cancel and

\[
\boxed{
\det J_8
=b^8c_1^7c_2^6c_3^5c_4^4c_5^3c_6^2c_7
\,\mu_0^8\Delta^{28}.
}
\tag{S2V29}
\]

Thus any fixed nonzero profile mass and any fixed positive center spacing give an explicit nonzero determinant margin.

## 7. Slowly varying coefficients

Restore bounded diagonal transport and slowly varying nonzero interaction coefficients. After integrating-factor normalization, the Volterra exit kernels depend continuously on the coefficient functions in the uniform topology.

Therefore, for the frozen determinant margin `d_8>0`, there exists a positive width/variation threshold `eta_8` such that

\[
\boxed{
|\det J_{8,var}|\ge d_8/2>0
}
\tag{S2V30}
\]

whenever the second collision collar is chosen short enough and the source-frame/curl perturbations are sufficiently small.

Let

\[
Y_{out}
=(C_{new},P,E,G_4,G_5,G_6,G_7,G_8)_{out}.
\tag{S2V31}

Prescribe

Y_*

\[
Y_{out}=Y^{(0)}+J_8p.

By (S2V26), the unique frozen principal solution is

\[
\boxed{
p=J_8^{-1}(Y_*-Y^{(0)}).}
\tag{S2V34}
\]

Thus the finite-dimensional rank obstruction for the sufficient clean routed second gate is closed.
