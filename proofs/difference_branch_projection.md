# Principal growing projection for the desired difference branch

**Status:** PROVED PRINCIPAL ALGEBRA for the reference beta-wave model. Localization/curl remainders are not included here.

## 1. Reference geometry

Work in the orthogonal frame \((e_r,K,N)\). For signed slope \(s\), use the source growing reference polarization

\[
g(s)=e_r-sK+c_0\sqrt{1+s^2}\,N,
\]

where \(c_0>0\) is the fixed source polarization constant.

Let

\[
k_j=\beta_j(s_j e_r+K),
\qquad
k_c=k_1-k_2=s_c e_r+K,
\]

with

\[
\beta_1-\beta_2=1,
\qquad
s_c=\beta_1s_1-\beta_2s_2.
\]

Take

\[
a_j=g(s_j).
\]

## 2. Difference-harmonic quadratic vector

The Fourier coefficient of the Navier–Stokes cross interaction at \(k_c=k_1-k_2\) is, up to the common scalar factor \(i\),

\[
B_-=(a_1\cdot(-k_2))a_2+(a_2\cdot k_1)a_1.
\]

Because

\[
a_1\cdot k_2=\beta_2(s_2-s_1),
\qquad
 a_2\cdot k_1=\beta_1(s_1-s_2),
\]

we get

\[
\boxed{
B_-=(s_1-s_2)(\beta_1a_1+\beta_2a_2).
}
\tag{D1}
\]

Write

\[
M=\beta_1s_1+\beta_2s_2,
\qquad
R=\beta_1\sqrt{1+s_1^2}+\beta_2\sqrt{1+s_2^2},
\]

\[
\beta_+=\beta_1+\beta_2.
\]

Then

\[
B_-=(s_1-s_2)\big(\beta_+e_r-MK+c_0RN\big).
\]

## 3. Leray projection onto the child divergence-free plane

The child wavevector is parallel to

\[
n_c=s_ce_r+K.
\]

A divergence-free basis for the child plane is

\[
h_c=e_r-s_cK,
\qquad N.
\]

Since

\[
\Pi_c e_r=\frac{h_c}{1+s_c^2},
\qquad
\Pi_c K=-\frac{s_ch_c}{1+s_c^2},
\qquad
\Pi_cN=N,
\]

we obtain

\[
\boxed{
\Pi_cB_-
=(s_1-s_2)
\left[
\frac{\beta_++s_cM}{1+s_c^2}h_c
+c_0RN
\right].
}
\tag{D2}
\]

The child growing/decaying reference vectors are

\[
g_c^+=h_c+c_0\sqrt{1+s_c^2}N,
\qquad
 g_c^-=h_c-c_0\sqrt{1+s_c^2}N.
\]

Writing

\[
\Pi_cB_-=A_+g_c^++A_-g_c^-,
\]

one gets

\[
\boxed{
A_+
=\frac{s_1-s_2}{2(1+s_c^2)}
\left[
\beta_++s_cM+R\sqrt{1+s_c^2}
\right].
}
\tag{D3}
\]

All terms in the bracket are positive for the current positive-slope relay witness. Hence

\[
\boxed{A_+\ne0.}
\]

Thus the desired difference harmonic has a genuinely nonzero growing-child component.

## 4. Quantitative v0.4 witness

For

\[
\beta_1=25/16,
\quad
\beta_2=9/16,
\quad
s_1=x_1=29/32,
\quad
s_2=y_0\approx1.2260460510,
\]

\[
s_c\approx0.7263647213.
\]

The bracket in (D3) is bounded away from zero. Numerically,

\[
\beta_++s_cM\approx3.65448,
\]

\[
R\sqrt{1+s_c^2}\approx3.70620.
\]

Consequently the growing coefficient is not a near-cancellation. A convenient conservative principal lower factor is

\[
\boxed{
|A_+|\ge0.38
}
\]

throughout a sufficiently small neighborhood of the certified resonance root. The numerical center value is substantially larger.

## 5. Scope

This lemma removes the **principal polarization nondegeneracy** obstruction for the corrected difference relay. It does not yet prove the localized source lower bound because the actual packets are generated by curls, carry slow cutoffs, and include \(W^{1-\kappa_s}\) remainders. The next step is to show those corrections cannot erase the positive margin in (D3).
