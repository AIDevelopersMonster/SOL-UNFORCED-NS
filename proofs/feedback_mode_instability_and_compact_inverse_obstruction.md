# Unstable feedback mode and compact-inverse obstruction

**Status:** PROVED MODEL/ODE OBSTRUCTION. This note corrects an overly optimistic version of the zero-force correction program. The first correction generation is not entirely stable: the parent/child/catalyst lattice contains a uniformly growing feedback mode. Moreover, a one-sided exponential-dichotomy inverse does not by itself produce a compactly supported correction; exact two-sided compact support imposes a compatibility condition.

## 1. General lattice-mode net rate

Use the v0.4 parent generators in the reference `(e_r,K)` plane,

\[
v_1=\beta_1(ux_1,1),
\qquad
v_2=\beta_2(uy,1),
\]

with

\[
\beta_1=\frac{25}{16},
\qquad
\beta_2=\frac9{16},
\qquad
x_1=\frac{29}{32},
\]

and `u=u_*>=20`.

For a lattice index `(a,b)`, write

\[
R_{a,b}=u(a\beta_1x_1+b\beta_2y),
\qquad
T_{a,b}=a\beta_1+b\beta_2.
\]

When `T_{a,b} != 0`, factor the normal as

\[
a v_1+b v_2
=T_{a,b}\left(\frac{R_{a,b}}{T_{a,b}},1\right).
\]

The source principal growth rate is homogeneous of degree zero in the normal direction while viscous damping is quadratic in its magnitude. After dividing by `lambda_0`, the exact reference net rate is therefore

\[
\boxed{
\Gamma_{a,b}(u,y)
=
\frac{|T_{a,b}|}{\sqrt{R_{a,b}^2+T_{a,b}^2}}
-
\frac{R_{a,b}^2+T_{a,b}^2}{(1+u^2)^{3/2}}.
}
\tag{F1}
\]

For `T_{a,b}=0`, the inviscid growing contribution vanishes and only the negative viscous term remains.

This formula is the lattice version of the beta-envelope derivative used elsewhere in the branch.

## 2. The first dangerous feedback mode `(1,-2)`

The interaction of the desired child `(1,-1)` with the negative catalyst harmonic `(0,-1)` produces

\[
(1,-1)+(0,-1)=(1,-2).
\]

Thus this mode is generated by parent-child feedback as soon as the child is nonzero.

For `(a,b)=(1,-2)`,

\[
T_{1,-2}
=\beta_1-2\beta_2
=\frac7{16}.
\tag{F2}
\]

On the certified reduced resonance bracket

\[
\frac{613}{500}\le y\le\frac{1227}{1000},

\[

r(y):=\beta_1x_1-2\beta_2y

Hence

\[
R_{1,-2}=ur(y)>0.
\]

The mode is therefore a nearly tangential carrier: its radial coefficient is small while its tangential coefficient remains `7/16`.

## 3. Uniform positive growth gap

Set

\[
r_+=\frac{2353}{64000},
\qquad T=\frac7{16}.
\]

Using

\[
\sqrt{u^2r^2+T^2}\le ur_++T
\]

and

\[
(1+u^2)^{3/2}\ge u^3,
\]

formula (F1) gives

\[
\Gamma_{1,-2}
\ge
\frac{T}{ur_++T}
-
\frac{u^2r_+^2+T^2}{u^3}.
\]

Multiplying by `u`,

\[
u\Gamma_{1,-2}
\ge
\frac{T}{r_++T/u}
-r_+^2-rac{T^2}{u^2}.
\]

For `u>=20`, the right-hand side is minimized by replacing `T/u` with `T/20` and `T^2/u^2` with `T^2/400`. Direct rational comparison gives

\[
\frac{T}{r_++T/20}
-r_+^2-rac{T^2}{400}

\]

Therefore

\[
\boxed{
\Gamma_{1,-2}(u,y)>\frac7u>0
}
\tag{F4}
\]

uniformly for `u>=20` and the whole certified bracket.

So `(1,-2)` is not a stable correction mode. It is a **uniformly growing feedback mode**.

At the exact `u=20` resonance root its dimensionless rate is approximately

\[
\Gamma_{1,-2}\approx0.527.
\]

This is larger than the corresponding unit-beta child rate at that relay location.

## 4. Consequence: stable-only contraction is false

The zero-force correction program cannot be based on the assertion

\[
\text{all non-designated low lattice modes are forward stable}.
\]

That assertion is false already at `(1,-2)`.

The correct linear architecture must use an **exponential dichotomy**:

- forward inverses for stable correction modes;
- backward/terminal inverses for unstable correction modes;
- a separate compatibility treatment for neutral/mean modes.

However, a second obstruction appears immediately: one-sided inverses do not automatically preserve compact support.

## 5. Exact compact-inverse compatibility condition

Consider the scalar equation on `[v_-,v_+]`

\[
z'(v)=a(v)z(v)+f(v).
\tag{F5}
\]

Let

\[
A(v)=\int_{v_-}^{v}a(s)\,ds.
\]

Multiplying (F5) by `e^{-A(v)}` gives

\[
\frac d{dv}\big(e^{-A(v)}z(v)\big)
=e^{-A(v)}f(v).
\]

Hence a solution satisfying **both** endpoint conditions

\[
z(v_-)=z(v_+)=0
\tag{F6}
\]

exists only if

\[
\boxed{
\int_{v_-}^{v_+}e^{-A(w)}f(w)\,dw=0.
}
\tag{F7}
\]

Conversely, if (F7) holds, the forward variation-of-constants solution with `z(v_-)=0` also satisfies `z(v_+)=0`. Thus (F7) is necessary and sufficient.

### Compact-inverse obstruction

A generic localized forcing `f` does **not** satisfy (F7). Therefore one cannot obtain an exactly compactly supported scalar correction merely by choosing the stable forward inverse or unstable backward inverse.

For an unstable mode the terminal inverse

\[
z(v)=-\int_v^{v_+}
\exp\left(-\int_v^w a(s)\,ds\right)f(w)\,dw
\]

is bounded when `a>=gamma>0`, but generically it leaves a nonzero value at `v_-`. Cutting that value off creates a new residual. The stable case is the time-reversed analogue.

## 6. What the source forced construction can do that the unforced target cannot

In the forced construction, exponentially small cutoff defects may ultimately be absorbed into the prescribed smooth external force. For the unforced target, condition (F7) or an exact compensating mechanism is required; exponential smallness alone does not make the defect disappear.

Thus the local exact correction problem has acquired a genuine finite-dimensional **solvability constraint** rather than merely a norm estimate.

## 7. Revised zero-force target

The correct next problem is not a naive contraction on arbitrary corrections. It is a **Lyapunov-Schmidt / dichotomy correction problem**:

1. split nonzero lattice modes into stable and unstable subspaces;
2. use forward/backward bounded inverses on those subspaces;
3. extract the finitely many endpoint/mean compatibility functionals like (F7);
4. use available relay design parameters (pulse translations, amplitudes/phases, or additional designated correction packets) to solve those compatibility equations exactly;
5. only then run a contraction on the complementary infinite-dimensional subspace.

This is a stricter and more accurate formulation of exact zero-force closure.
