# One-sided radial characteristic inverse for the mean block

**Status:** PROVED MODEL INVERSE / CANDIDATE EXACT-CLOSURE ROUTE.

This note replaces the compact two-sided radial primitive used in the source construction by a one-sided input-output inverse on a bounded radial collar. The point is analogous to `characteristic_fast_time_mean_inverse.md`: if the local relay is allowed to carry an outgoing trace, there is no need to force every correction to vanish at both radial ends.

## 1. Straightened radial operator

On a fixed common torus chart the relevant source operator has the form

\[
D_r=\partial_R+M_r d_rR^{d_r-1}v_r\cdot\partial_y.
\]

Set

\[
U=R^{d_r}.
\]

Then on a collar `U in [U_-,U_+]` the characteristic field is

\[
\boxed{
\mathcal T_r
=\partial_U+M_r v_r\cdot\partial_y.
}
\tag{RF1}
\]

Up to the fixed bounded Jacobian factor between `partial_R` and `partial_U`, this is the radial transport operator that must be inverted.

## 2. Exact entrance-value inverse

For a source `F(U,y)` define

\[
\boxed{
(\mathcal K_rF)(U,y)
=
\int_{U_-}^{U}
F\bigl(\sigma,y+M_r(U-\sigma)v_r\bigr)\,d\sigma.
}
\tag{RF2}
\]

A direct differentiation gives

\[
\boxed{
\mathcal T_r\mathcal K_rF=F,
\qquad
(\mathcal K_rF)|_{U=U_-}=0.
}
\tag{RF3}
\]

Changing orientation gives the analogous exit-value inverse from `U_+`.

No torus Fourier division and no Diophantine denominator occur in this formula.

## 3. Translation-invariant norm bound

Let `X_y` be any translation-invariant Banach norm on the auxiliary torus. Since translation in `y` is an isometry,

\[
\boxed{
\sup_{U\in[U_-,U_+]}
\|\mathcal K_rF(U)\|_{X_y}
\le
(U_+-U_-)
\sup_{U\in[U_-,U_+]}
\|F(U)\|_{X_y}.
}
\tag{RF4}
\]

This estimate is independent of `M_r`.

For physical-jet norms built from `mathcal T_r`, torus derivatives, and the remaining slow variables, the same argument gives

\[
\boxed{
\|\mathcal K_rF\|_{\mathfrak R^m_{\rm char}}
\le C_m\|F\|_{\mathfrak R^m_{\rm char}}.
}
\tag{RF5}
\]

Thus the radial inverse is derivative-loss free in the characteristic formulation.

## 4. Weighted radial divergence operators

The source pressure/stress equations use

\[
(D_r+e/R)\phi=f,
\qquad e\in\{0,1,2\}.
\]

Multiplying by `R^e` gives

\[
D_r(R^e\phi)=R^ef.
\]

Hence the one-sided inverse is explicit:

\[
\boxed{
\phi(R,y)
=R^{-e}
\mathcal K_r\bigl[R^ef\bigr](R,y),
}
\tag{RF6}
\]

with the chosen entrance trace set to zero. On a collar bounded away from `R=0`, multiplication by `R^{+/-e}` is uniformly bounded, so (RF4)-(RF5) persist.

## 5. What changes relative to the source compact inverse

The source compact primitive enforces vanishing outside the radial patch. That requirement creates a weighted moment condition and the cutoff remainder `A_e` analyzed in `radial_gevrey_radius_loss_and_same_space_obstruction.md`.

The forward inverse (RF6) does not impose two-sided radial compact support. Instead it prescribes one radial boundary value and produces an outgoing trace at the opposite face:

\[
\boxed{
\phi_{\rm out}(y):=\phi(R_+,y).
}
\tag{RF7}
\]

Thus the radial compactification defect is exchanged for boundary data, exactly as the temporal input-output formulation exchanges compact temporal support for the outgoing correction `Z_out`.

## 6. Compatibility with the relay philosophy

The v0.8 architecture already treats the relay as a local map carrying state from an entrance face to an exit face. It is therefore natural to enlarge the local state by the finite collection of radial mean traces generated by pressure/stress reconstruction.

Schematically,

\[
\boxed{
(m_{\rm in},z_{\rm in},r_{\rm in})
\longmapsto
(m_{\rm out},z_{\rm out},r_{\rm out}),
}
\tag{RF8}
\]

where `r` denotes the radial trace data required by the weighted mean inverses.

In this formulation the radial inversion itself contributes an `O(1)` bounded operator, not a small operator. Smallness must come from the nonlinear source placed into it. This is acceptable for a Banach contraction provided every differentiated nonlinear mean source carries a positive small factor.

## 7. Remaining nonlinear estimate

Let `delta m=m-tilde m` and `delta z=z(m)-z(tilde m)`. After moving all linear mean terms into the exact forward mean propagator, the differentiated radial source must satisfy a bound of the form

\[
\boxed{
\|\delta F_{\rm rad}\|_{G^s_L}
\le
C_MS_*^C
\Bigl(
\varepsilon^{0.9-2\kappa_s}
+\varepsilon^{1/2-\kappa_s}
+\rho_\ell
\Bigr)
\|\delta m\|_{G^s_L}.
}
\tag{RF9}
\]

If (RF9) is proved in the same characteristic Gevrey norm used by the temporal inverse, then (RF4) gives the same small factor after radial inversion and the compactification remainder disappears entirely from the exact fixed-point problem.

The signed-stress covariance branch must be included in `F_rad`; it cannot be hidden inside an unspecified bounded correction.

## 8. Exact local theorem target after radial forwardization

The natural target is therefore not a compactly supported mean correction theorem but a **coupled characteristic input-output theorem**:

> For one frozen v0.8 design and all sufficiently large dyadic levels, the complete mean/nonzero system on a bounded temporal-radial relay collar defines an exact local map between entrance and exit states, and its nonlinear part has Lipschitz norm `eta_l=o(1)` in one fixed positive-radius characteristic Gevrey space.

Under that statement Banach contraction closes the exact local unforced relay without Nash--Moser and without an infinite radial compactification series.

## 9. What is and is not proved here

Proved here:

- exact one-sided inversion of the radial characteristic operator;
- no torus derivative loss;
- no Diophantine denominator;
- boundedness in translation-invariant and characteristic norms;
- reduction of the compact radial obstruction to an outgoing-trace formulation.

Not yet proved:

- that the source mean equations can be reorganized globally on the full collar so that all required pressure/stress variables may use the one-sided radial boundary condition simultaneously;
- the quantitative differentiated nonlinear source estimate (RF9);
- preservation/inheritance of the radial exit traces at the next physical-scale relay.

These are now the sharp obligations for the radial route.
