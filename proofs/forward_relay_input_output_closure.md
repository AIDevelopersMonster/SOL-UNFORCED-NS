# Forward input-output closure of the v0.8 relay

**Status:** PROVED ABSTRACT/LOCALIZED BANACH CLOSURE THEOREM under the packet estimates already established in this branch. This theorem removes the need for a separate compact-support compatibility equation for every critical mode by changing the local formulation: the relay is treated as an exact forward initial-value map on a bounded characteristic collar, not as a compactly supported correction that vanishes at both temporal ends.

The theorem gives exact zero residual **inside the relay collar**. It does not yet prove that the outgoing correction can be inserted into the next physical-scale relay without loss; that is the physical-scale inheritance problem.

## 1. Local correction equation

Fix one admissible v0.8 design and one sufficiently large dyadic level. Let

\[
I=[v_-,v_+]
\]

be a bounded relay collar. Write the exact localized field as

\[
U=U_{\rm des}+Z,
\]

where `U_des` contains the two designated parent packets and the desired child component generated by their difference interaction.

The exact residual equation on the collar is

\[
\boxed{
\mathcal L(v)Z
=F_{\rm flat}(v)+\mathcal B(Z,Z)+\mathcal B(Z,U_{\rm des})+\mathcal B(U_{\rm des},Z).
}
\tag{IO1}

The forcing `F_flat` here is **not an external force**. It is the internal non-designated residual of the approximate relay before correction. `source_localized_action_preservation.md` gives

\[
\boxed{
\|F_{\rm flat}\|_{\mathfrak A_\sigma^{(0)}}
\le\rho_\ell,
\qquad
\rho_\ell=C_MS_*^{C_M}e^{-c_MS_*}.
}
\tag{IO2}

## 2. Forward evolution on every lattice mode

For each lattice mode `nu`, let `V_nu(v,w)` denote the fundamental propagator of the exact localized linearized coefficient equation.

On the finite critical block, the coefficients are smooth on the fixed compact collar, so for each frozen design there is a finite constant `K_{crit,M}` such that

\[
\boxed{
\|V_\nu(v,w)\|\le K_{crit,M}
\qquad
(v_-\le w\le v\le v_+,\ \nu\in\mathcal C_M).
}
\tag{IO3}

No compatibility condition is needed because we impose only the entrance value

\[
Z(v_-)=Z_{\rm in}.
\]

On the infinite stable complement, `finite_critical_block_uniform_stable_inverse.md` gives the stronger uniform bounds and quadratic high-mode smoothing.

Combining the finite critical block and stable complement therefore yields one forward propagator on the full analytic lattice packet space:

\[
\boxed{
\|\mathcal V(v,w)f\|_{\mathfrak A_\sigma}
\le K_M\|f\|_{\mathfrak A_\sigma}
}
\tag{IO4}

for `v_-<=w<=v<=v_+`, with `K_M<infinity` depending on the frozen design and collar but **not** on correction stage or lattice truncation.

For the stable high-frequency component one retains the modewise two-power smoothing from the previous theorem.

## 3. Duhamel map

The exact initial-value equation is equivalent to

\[
\boxed{
Z(v)
=\mathcal V(v,v_-)Z_{\rm in}
+
\int_{v_-}^{v}
\mathcal V(v,w)
\left[
F_{\rm flat}(w)+\mathcal N(Z(w))
\right]dw,
}
\tag{IO5}

where

\[
\mathcal N(Z)
=\mathcal B(Z,Z)
+\mathcal B(Z,U_{\rm des})
+\mathcal B(U_{\rm des},Z).
\]

Use the Banach space

\[
\mathfrak X
=C(I;\mathfrak A_\sigma)
\]

with norm

\[
\|Z\|_{\mathfrak X}
=\sup_{v\in I}\|Z(v)\|_{\mathfrak A_\sigma}.
\]

## 4. Small mixed term

The designated relay packets themselves are not small in the raw packet normalization, but the correction equation is written after extracting the exact principal designated child interaction into `U_des`. Every **non-designated** mixed output from `B(Z,U_des)` or `B(U_des,Z)` inherits either:

1. a stable high-mode inverse gain; or
2. the v0.8 action-subcritical factor from the global action filter and its source-localized preservation theorem.

Therefore the already-proved packet calculus gives, after choosing the dyadic level sufficiently large,

\[
\boxed{
\left\|
\int_{v_-}^{v}
\mathcal V(v,w)
[\mathcal B(Z,U_{\rm des})+\mathcal B(U_{\rm des},Z)]dw
\right\|_{\mathfrak X}
\le\eta_\ell\|Z\|_{\mathfrak X},
}
\tag{IO6}

where

\[
\eta_\ell\to0
\qquad(\ell\to\infty).
\]

This is exactly the place where the action filter is used: a critical mode may grow locally, but every non-designated route into it is born with the fixed action deficit.

## 5. Quadratic estimate

`analytic_quadratic_symbol_bound.md` and the full forward propagator give

\[
\boxed{
\left\|
\int_{v_-}^{v}
\mathcal V(v,w)\mathcal B(Z,Z)(w)dw
\right\|_{\mathfrak X}
\le C_M\|Z\|_{\mathfrak X}^2.
}
\tag{IO7}

Similarly,

\[
\boxed{
\|\mathcal Q(Z)-\mathcal Q(\widetilde Z)\|_{\mathfrak X}
\le C_M
(\|Z\|_{\mathfrak X}+\|\widetilde Z\|_{\mathfrak X})
\|Z-\widetilde Z\|_{\mathfrak X}.
}
\tag{IO8}

## 6. Exact zero-force contraction

Assume an incoming correction satisfying

\[
\boxed{
\|Z_{\rm in}\|_{\mathfrak A_\sigma}
\le\rho_\ell.
}
\tag{IO9}

By (IO2), (IO4), and the fixed collar length,

\[
\left\|
\mathcal V(v,v_-)Z_{\rm in}
+
\int_{v_-}^{v}\mathcal V(v,w)F_{\rm flat}(w)dw
\right\|_{\mathfrak X}
\le C_M\rho_\ell.
\tag{IO10}

Choose

\[
R_\ell=2C_M\rho_\ell.
\]

Since

\[
\rho_\ell\to0,
\qquad
\eta_\ell\to0,
\]

for all sufficiently large `ell` we have

\[
\eta_\ell+2C_MR_\ell<\frac12.
\tag{IO11}

Then the Duhamel map defined by the right-hand side of (IO5) maps the closed ball

\[
B_{R_\ell}\subset\mathfrak X
\]

into itself and is a strict contraction. Hence there exists a unique exact correction

\[
\boxed{Z\in B_{R_\ell}}
\tag{IO12}
\]

solving the full local residual equation.

Therefore

\[
\boxed{
R(U_{\rm des}+Z)=0
\qquad\text{throughout the relay collar.}
}
\tag{IO13}

No external force is used.

## 7. Outgoing state

The price for eliminating the enormous compact-support compatibility block is that one does **not** require

\[
Z(v_+)=0.
\]

Instead the correction exits with the relay as part of the outgoing state:

\[
\boxed{Z_{\rm out}:=Z(v_+).}
\tag{IO14}

The contraction estimate gives

\[
\boxed{
\|Z_{\rm out}\|_{\mathfrak A_\sigma}
\le R_\ell
\le C_MS_*^{C_M}e^{-c_MS_*}.
}
\tag{IO15}

Thus the outgoing non-designated correction is exponentially action-subcritical.

The designated child amplitude is not included in `Z_out`; it belongs to `U_des` and is the intended primary output of the relay.

## 8. Relay input-output theorem

For every frozen sufficiently large v0.8 design `M`, there exists a sufficiently large dyadic threshold such that the localized relay defines an exact nonlinear map

\[
\boxed{
\mathscr R_\ell:
(Z_{\rm in},A_{1,\rm in},A_{2,\rm in})
\mapsto
(A_{c,\rm out},Z_{\rm out})
}
\tag{IO16}

with the following properties:

1. the field solves the unforced localized Navier-Stokes equation exactly inside the relay collar;
2. the desired difference interaction produces the designated growing child channel;
3. every non-designated outgoing lattice component belongs to `Z_out` and satisfies the flat bound (IO15);
4. the map is locally Lipschitz in the analytic packet norm;
5. no two-sided compact temporal support and hence no `Theta(M^5)` family of endpoint compatibility equations is required.

This is the natural local object for an autonomous cascade: a relay should transport a small incoming error into a small outgoing error, not erase all memory at every intermediate collar.

## 10. New global frontier

Once the local relay is formulated as an input-output map, the next genuinely new mathematical problem is no longer local compatibility. It is **physical-scale inheritance**:

\[
\boxed{
\text{Does }(A_{c,\rm out},Z_{\rm out})
\text{ at physical scale }q_j
\text{ enter the next relay at }q_{j+1}<q_j
\text{ with the required parent/catalyst geometry and the same flat error class?}
}
\tag{IO17}

The local zero-force module is useful only if that inheritance map can be iterated without losing the growing child or accumulating the exponentially small error tail.
