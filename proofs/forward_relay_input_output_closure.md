## 1. Local correction equation

Fix one admissible v0.8 design and one sufficiently large dyadic level. Let

\[
I=[v_-,v_+]
\]

be a bounded relay collar. Write the exact localized field as

\[
U=U_{\rm des}+Z,
\]

where `U_des` contains the two designated parent packets and the desired child component generated by their difference interaction.

The exact residual equation on the collar is

\[
\boxed{
\mathcal L(v)Z
=F_{\rm flat}(v)+\mathcal B(Z,Z)+\mathcal B(Z,U_{\rm des})+\mathcal B(U_{\rm des},Z).
}
\tag{IO1}
\]

The forcing `F_flat` here is **not an external force**. It is the internal non-designated residual of the approximate relay before correction. The original form of this note stated the stronger estimate

\[
\boxed{
\|F_{\rm flat}\|_{\mathfrak A_\sigma^{(0)}}
\le\rho_\ell,
\qquad
\rho_\ell=C_MS_*^{C_M}e^{-c_MS_*}.
}
\tag{IO2-historical}
\]

That estimate is also superseded for the full supported stage-zero defect. The current conservative defect size is

\[
\boxed{
\rho_\ell
\lesssim
S_*^C\varepsilon^{1/5}+S_*^Ce^{-c_MS_*}.
}
\tag{IO2-current}
\]

## 2. Forward evolution on every nonzero lattice mode

For each nonzero lattice mode `nu`, let `V_nu(v,w)` denote the fundamental propagator of the exact localized linearized coefficient equation.

On the finite critical block, the coefficients are smooth on the fixed compact collar, so for each frozen design there is a finite constant `K_{crit,M}` such that

\[
\boxed{
\|V_\nu(v,w)\|\le K_{crit,M}
\qquad
(v_-\le w\le v\le v_+,\ \nu\in\mathcal C_M).
}
\tag{IO3}
\]

No compatibility condition is needed because we impose only the entrance value

\[
Z(v_-)=Z_{\rm in}.
\]

On the infinite stable complement, `finite_critical_block_uniform_stable_inverse.md` gives the stronger uniform bounds and quadratic high-mode smoothing.

Combining the finite critical block and stable complement therefore yields one forward propagator on the full **nonzero-harmonic** analytic lattice packet space:

\[
\boxed{
\|\mathcal V(v,w)f\|_{\mathfrak A_\sigma}
\le K_M\|f\|_{\mathfrak A_\sigma}.
}
\tag{IO4}
\]

## 3. Duhamel map on the nonzero block

The exact initial-value equation for the nonzero block is equivalent to

\[
\boxed{
Z(v)
=\mathcal V(v,v_-)Z_{\rm in}
+
\int_{v_-}^{v}
\mathcal V(v,w)
\left[
F(w)+\mathcal N(Z(w))
\right]dw.
}
\tag{IO5}
\]

The important correction made later in `nonzero_harmonic_forward_reduction.md` is that the mixed designated terms are not simply a small operator: they must be absorbed into the full linearized evolution.

## 4. What survives from this note

The architectural lesson survives unchanged:

- use a forward initial-value problem rather than impose vanishing at both temporal ends;
- allow a small outgoing correction rather than solve a large endpoint compatibility system;
- treat the relay as an input-output map;
- carry state to the next stage instead of erasing it at every collar.

The detailed nonzero-harmonic implementation of that idea is now `nonzero_harmonic_forward_reduction.md`.

## 5. What does not survive

The following statements from the original version are withdrawn:

\[
R(U_{\rm des}+Z)=0
\quad\text{for the complete local field},
\]

and the corresponding claim that the local zero-force problem is already closed.

The angular mean is generated by quadratic conjugate-wave interactions and is not represented by the nonzero two-generator lattice. It has its own pressure/stress, temporal zero-average, radial compactification, covariance, and five-dimensional moment equations.

Therefore the current valid reduction is

\[
\boxed{
\text{exact nonzero harmonics }z=z(m)
\quad\Longrightarrow\quad
\text{one remaining coupled angular-mean problem for }m.
}
\tag{IO6-current}
\]
