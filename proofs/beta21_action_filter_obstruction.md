# Explicit action-filter obstruction for the ordered beta-(2,1) reset supercell

**Status:** PROVED REDUCED/PRINCIPAL OBSTRUCTION TO THE CURRENT UNGATED SUPERCell. The causal ordered reset candidate passes phase, action, polarization, and timing tests, but it does **not** satisfy the v0.8-style full principal-growing action filter. An explicit beta-one lattice descendant has a large positive action defect.

This does not rule out all repairs. It rules out carrying the current two-unit-beta bank through infinitely many cells while treating every non-designated growing harmonic by the existing uniform action-gap mechanism. A support-gated circuit, an independent phase bank, or a different small-divisor geometry would be required.

## 4. Why the witness is structurally natural

For beta one we have `m+n=1`, so `n=1-m` and

\[
\xi_{m,1-m}(t)
=\left|x+t+(1-2m)\delta\right|.
\tag{AF13}
\]

Thus the unit-beta descendant slopes form an arithmetic progression of spacing `2delta`. At the working point

\[
\frac{x+s}{\delta}\approx13.10635,
\]

so the odd lattice site `2m-1=13` (`m=7`) almost cancels the central slope. This is exactly the opposite of the large-`M` half-step protection in v0.8: there the lattice spacing shrinks while reaching a near-zero slope costs genealogy depth `Theta(M)`, whereas here the fixed spacing places a near-zero unit-beta character at bounded depth `13`.

## 6. A small-`delta` tension for the same-bank reset mechanism

The natural cure for (AF13) is to force `delta` very small, recreating the v0.8 small-divisor protection. But the present finite reset tree has an opposing action constraint.

Suppose `delta->0` and all late event offsets are `O(delta)`. The first relay equation

\[
I_2(x)+I_1(x+\delta)-I_1(x-\delta)=0
\]

forces

\[
\boxed{x\to a_*:=2^{-2/3}.}
\tag{AF14}
\]

At this point

\[
I_2(a_*)=0,
\qquad
I_1(a_*)<0.
\tag{AF15}
\]

Any nontrivial bounded-depth reset character constructed from a fixed number of the same unit-beta `C,D` leaves carries, at leading order, a strictly negative integer multiple of `I_1(a_*)`; propagation over `O(delta)` changes the action only by `o(1)`. Hence it cannot converge to the required beta-two reset action `I_2(x)->0`.

For the present six-leaf action ledger the contradiction is explicit: as `delta,s,T->0`,

\[
\mathcal A_{\rm reset}\to6I_1(a_*)<0,
\]

whereas

\[
I_2(x)\to0.
\tag{AF16}
\]

Thus the current same-bank microcascade cannot simultaneously enter the `delta->0` small-divisor regime and retain exact action renewal by only a bounded vanishing-time perturbation.
